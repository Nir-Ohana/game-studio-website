# Website SEO implementation plan

**Goal:** Publish discoverable, accurate pages for Ohana Studios and both games, and measure the live site's performance.

**Design:** Keep the existing homepage and visual style. Share game content with dedicated `/shelly-jigsaw/` and `/rocket-rabbit/` pages. Use static Astro output, canonical trailing-slash URLs, a generated sitemap, crawlable links, and Organization, WebSite, WebPage, VideoGame and BreadcrumbList JSON-LD. Both games remain in development; omit unverified launch dates, store offers and ratings.

**Authorization:** The user requested this SEO pass and previously confirmed publishing site updates. Implement inline and deploy using the existing GitHub Pages workflow.

## Work

- [x] Add build-output checks for discoverable game pages, unique metadata, valid structured data and sitemap/robots consistency. Confirm they fail against the current build.
- [x] Extract shared game content, add detail pages and link them from the homepage and footer. Add canonical metadata, JSON-LD, sitemap integration and robots.txt. Preserve the privacy route and legacy redirect.
- [x] Measure performance and address observed image/font bottlenecks. Check mobile layouts, links, image loading and the complete SEO test suite.
- [x] Review the changes, commit, push and monitor GitHub Pages. Verify production routes, metadata, sitemap, robots and mobile Lighthouse results.
- [x] Check Google indexing and Search Console where access permits. Record the distinction between public crawlability, indexing evidence, laboratory metrics and field Core Web Vitals; document any access requirement.

## Review focus

- Canonicals, internal links and sitemap URLs agree, including trailing slashes.
- Game metadata describes the visible game and does not imply an available release.
- Structured JSON parses safely and connects pages, games, breadcrumbs and publisher.
- Images and fonts load without causing layout shifts or mobile overflow.
- Publishing preserves privacy-policy and app-ads.txt URLs.

## Validation

Run `npm run check`, `npm run build`, and `npm run test:seo`. Exercise the built and live sites in Chromium at desktop and mobile sizes. Save Lighthouse reports outside the repository and summarize results in `docs/seo.md`.
